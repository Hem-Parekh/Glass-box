    What this tool reads: the CMA rows and inputs it needs

    The CMA workbook. An .xlsx file in the Indian bank CMA layout. The tool reads the first sheet and finds rows by the label text in column A, so row numbers can differ between files.

    • A header row within the first 11 rows with 4-digit years in columns B to E (for example 2025, 2026, 2027, 2028).
    • The row directly under it holds the status: Actuals, Estimated or Projections.
    • Figures in Rs crore. The base year is the latest column with net sales above zero.

    Rows marked required stop the report with a clear message if they are missing. Other rows count as zero when absent.

    Project inputs come from the company's DPR or the promoter: project cost and working-capital margin, existing and new capacity, utilisation ramp, cost saving per unit, new fixed cost, and the loan terms. Industry presets fill the lender norms and you can edit every one.
